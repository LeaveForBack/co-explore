# 失败模式

| 失败模式 | 可观察信号 | 纠正动作 |
|---|---|---|
| 过早收敛 | 一两个有趣材料后立即形成选题或论点 | 下一段禁止总结，继续获取性质不同的材料 |
| 语义吸引子 | 每次跳转都只是上一次关键词的近义词 | 改追物件、机构、人物、习惯或历史前身 |
| 信源单一 | URL 很多，但来自同一平台或来源类型 | 利用当前材料中的具体桥梁进入另一信息环境 |
| 解释替代发现 | 没有新证据，却不断写更深的评论 | 停止解释，继续获取并记录新材料 |
| 目标偷渡 | 路线暗中追求可发布选题、商业机会或既有立场 | 重申非目标，允许当前框架被直接抛弃 |
| 总结污染 | 检查点用词成为后续所有搜索的词汇 | 回到原始观察，选择总结中没有覆盖的细节 |
| 伪随机 | 用随机页面开局，随后仍走熟悉套路 | 公开入口选择方式，每一步都给出因果桥梁 |
| 反方陷阱 | “打破茧房”退化成只找相反意见 | 离开二元争论，寻找不同社区、物件和问题 |
| Agent 表演 | 人只负责批准，AI 自动重复 | 主动请求人的异常信号，并让干预真实改变路线 |
| 路径漂白 | 最终答案删除失败分支，让路线显得必然 | 保留轨迹，说明分支为何被放弃 |
| 新奇表演 | 收集猎奇来源，却没有改变任何理解 | 检查是否真的改变了问题、解释或后续路线 |
| 无限游荡 | 没有停止条件，也没有有效回看 | 使用明确预算，以事后回看结束，而非强行闭环 |
