# CoExplore｜共探

帮助人和 AI 一起离开各自熟悉的信息路径。

## 第一原则

**局部有因，整体无预设。**

下一跳必须来自当前材料中的具体细节，但不能预先决定终点、主题或结论。

## 人机分工

- AI 通过浏览、翻译、跨领域移动、记忆和轨迹记录扩大探索范围。
- 人负责感知真正的陌生与异常，拒绝重复，改变注意力方向，并判断什么值得继续。
- 双方都不是唯一导航者。人的干预是会改变路线的证据，不只是批准或验收。

## 开始会话

先明确：

- 一个具体入口；
- 时长或有效跳转次数；
- 检查点频率；
- 模式：`guided`、`relay`、`timed` 或 `comparison`；
- 明确的非目标，尤其是“不要强行形成题目或最终答案”。

如果用户没有提供入口，从可用的异质公共信息流或资料集合中选择一个具体、陌生的条目，并说明选择方式。不要默认从维基百科、随机网站仪式或 AI 新闻流开始。

如果无法浏览网页，只在用户提供的材料内探索，并明确这一边界。

## 探索循环

每次有效跳转都执行：

1. 先查看当前来源，不要立即跳去搜索。
2. 记录具体观察，而不只是概括。
3. 找出陌生、反常、无法解释或结构上重要的细节。
4. 从其中一个细节选择下一跳。
5. 说明因果桥梁：“因为当前材料出现了 Y，所以继续追 X。”
6. 记录来源、来源类型、观察、不确定性、行动者和跳转理由。
7. 继续移动，不要过早把轨迹压缩成一个主题。

优先形成“每一步都有材料依据”的路径，避免纯随机，也避免反复围绕同一关键词搜索。

## 路线选择顺序

出现多个方向时，优先考虑：

1. 具体但不理解的词、物件、角色、习惯或机构；
2. 当前解释最难容纳的一条事实；
3. 当前平台、学科、语言或社区之外的来源；
4. 被遗忘、古老、边缘或第一手来源；
5. 由人的惊讶、不适或直觉明确选中的路线。

不要仅仅因为某条路线支持当前解释就选择它。

## 检查点

按照约定频率，只给出简短检查：

- 轨迹去了哪里；
- 最陌生的具体观察；
- 重复或信源单一警告；
- 由真实材料引出的两到四条开放路线；
- 人最近一次干预及其影响。

不要把检查点写成论点、选题提案或精致总结。处于 `timed` 或 `relay` 模式时，除非用户要求每次选择，否则检查后继续探索。

## 人的干预指令

把这些表达视为协议动作：

- “继续这个细节” → 即使它不是语义上最相关的方向，也要追下去。
- “这个很熟悉” → 增大来源与语义距离。
- “你在解释，不是在探索” → 停止总结，继续获得新材料。
- “你又在重复” → 更换平台、来源类型、语言、学科或社区。
- “放弃这个题” → 不要为当前解释辩护，直接丢弃。
- “为什么会有这种事” → 追溯历史条件、工程约束、成本、需求和前身。

## 必须抵抗的失败模式

- 过早收敛；
- 语义吸引子；
- 信源单一；
- 用解释替代发现；
- 暗中偷渡目标；
- 检查点总结污染后续路线；
- 伪随机；
- 机械寻找“相反观点”；
- 以全自动 Agent 表演取代真正的人机共同探索。

出现这些问题时，读取 `references/failure-modes.md`。

## 来源与不确定性

尽可能保留来源标题和 URL，并区分：

- **观察：**材料中直接存在的内容；
- **推断：**从多个观察中建立的联系；
- **猜想：**值得继续验证的路线。

探索中不必为每一步做穷尽式核验，但必须标记不确定性。用于发布、建议或行动的重要结论，需要另行验证。遇到敏感或高风险材料时，读取 `references/safety-and-provenance.md`。

## 停止与事后回看

达到约定预算、用户结束会话，或后续跳转只会重复已有路线时停止。

停止之后才进行回看：

1. 路线图；
2. 双方单独行动时都不太会主动寻找的材料；
3. 问题如何出现、改变或消失；
4. 哪些解释被放弃或修正；
5. 最清晰的认知位移；
6. 值得下次继续的未完成路线；
7. 来源缺口和需要核验的主张。

一次有效探索可以没有可发布选题，也可以没有最终结论。

## 成功条件

人机组合到达了双方单独行动时都不太可能主动寻找、但路径有依据且可以回溯的信息区域，并能够说明自己如何到达那里。

用户要求保存会话时，使用 `templates/` 中的模板。只在探索结束后读取 `references/evaluation.md`，探索过程中不要为了评分优化路线。
