# Failure modes

These categories were not invented in advance. They repeatedly appeared in real human–AI exploration runs. They are repeated field observations meant to keep exploration from collapsing back into familiar paths.

## Premature convergence
A plausible explanation appears and the rest of the run becomes evidence collection. Fix: seek the concrete fact the current explanation handles worst.

## Semantic attractor
The trail repeatedly returns to the same AI, tech, news, paper, or familiar industry cluster. Fix: change platform, era, community, language, or source type — not merely keywords.

## Source monoculture
Many URLs come from the same information ecology. Fix: track source types and force an environment shift after repeated homogeneous hops.

## Explanation replacing discovery
The prose gets deeper while the evidence stops changing. Fix: stop commentary; the next action must acquire a new source or object.

## Hidden objective smuggling
The run claims to be open-ended while secretly optimizing for a good topic, business opportunity, or conclusion. Fix: return to a budget-only objective and allow the run to yield nothing publishable.

## Checkpoint contamination
A polished checkpoint becomes the new topic and later navigation starts serving it. Fix: checkpoints contain observations, repetition warnings, and live branches — no thesis.

## Fake randomness
In a real parallel run, independent agents both chose Wikipedia as a “random” starting point; after being challenged, they again drifted toward a similar alternative random site. Every “random” run visits a small set of familiar entry points. Fix: randomness may choose a seed pool, but later hops must be materially caused and the seed-selection method should be visible.

## Mechanical opposition
“Break the filter bubble” becomes “show the opposite political view.” Fix: prefer leaving the frame entirely over moving to the other side of the same axis.

## Autonomous-agent theater
The AI browses many pages while the human only waits for the output. Fix: expose real branch points so human strangeness and rejection can change the route.
