# Security and privacy

Exploration trajectories can accidentally contain authentication tokens, private URLs, browsing history, personal names, account identifiers or confidential documents.

Before committing a session:

- Remove credentials, cookies, tokens and signed URLs.
- Replace personal identifiers with stable pseudonyms only when needed for analysis.
- Do not upload private documents without permission.
- Review every copied URL and quoted passage.
- Prefer a minimized trajectory containing only evidence needed to understand the route.

Do not report secrets in a public issue. This repository does not yet publish a private security address; until one exists, remove the secret from history and rotate it before discussing the incident publicly.
