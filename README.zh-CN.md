# CoExplore｜共探

[English](README.md)

**人与 AI 共同探索，走出各自熟悉的信息路径。**

多数 AI 研究工具从一个明确问题出发，不断追求相关性和收敛。CoExplore 从一个具体入口出发，暂缓形成结论，让人和 AI 互相打断惯性，直到发现双方单独行动时都不太可能遇到的材料与问题。

> 搜索回答你已经知道如何提问的问题；共探帮助你发现从未想过的问题。

## 适用人群

| 你是…… | 可以用它…… |
|---|---|
| 内容创作者、独立研究者 | 找到陌生材料和新问题 |
| 创业者、产品与战略人员 | 探索非显而易见的需求、用户与机会 |
| 跨学科研究者、学习者 | 离开熟悉术语、信源和引用网络 |
| Agent 开发者 | 研究与评估人机开放式探索 |
| 有好奇心的互联网用户 | 找回有路径依据、又不被预设目标束缚的偶遇感 |

**不适合：**明确事实查询、穷尽式文献综述、紧急排障和高风险决策。这些任务应使用搜索或 Deep Research。

## 核心原则

**局部有因，整体无预设。**

每一步都要由当前材料中的具体细节触发，但终点不能在出发前被决定。

- **AI** 负责扩大范围：浏览、翻译、跨领域移动、保存记忆和记录轨迹。
- **人** 负责感知异常：指出“这很陌生”“你又在重复”“继续追这个细节”“放弃当前解释”。

## 工作方式

1. **设定预算，不设定结论。** 明确时长、步数和检查频率。
2. **从具体入口开始。** 页面、物件、词语、社区、图片或事件都可以。
3. **跟随材料，不跟随预设主题。** 下一跳必须来自真实看到的细节。
4. **延迟总结。** 先记录，后解释；探索途中不强行形成题目。
5. **共同检查。** 在检查点识别重复，并决定下一段路线。
6. **结束后再回看。** 梳理路线、问题变化、被推翻的解释和认知位移。

## 快速开始

仓库包含中英文两个可安装 Skill，选择其中一个安装即可。

### 中文版

```bash
mkdir -p ~/.claude/skills
cp -R skills/co-explore-zh ~/.claude/skills/
```

调用：

```text
/co-explore-zh 从这个页面出发，探索 12 次有效跳转，每 4 次做一次检查，不要过早形成主题。
```

### 英文版

```bash
mkdir -p ~/.claude/skills
cp -R skills/co-explore ~/.claude/skills/
```

仅在单个项目中使用时，把所选目录复制到项目内的 `.claude/skills/`。

Skill 采用可移植的 `SKILL.md` 结构，不依赖特定厂商的运行时扩展。具备网页浏览能力时效果最好，也可以在用户提供的文件、网页集合或资料目录内探索。

## 每次探索应留下什么

- **探索轨迹：**去了哪里，每一步为什么发生。
- **陌生材料：**在解释之前值得保留的具体事实与细节。
- **问题变化：**最初的问题如何被改写、替换或抛弃。
- **事后回顾：**双方单独行动时不会主动寻找的发现，以及尚未走完的路线。

## 可选工具

创建一次探索会话：

```bash
python3 scripts/new_session.py \
  --lang zh-CN \
  --seed "一个社区维修活动页面" \
  --mode guided \
  --budget-type steps \
  --budget-value 12
```

校验轨迹：

```bash
python3 scripts/validate_trajectory.py benchmark/sample-trajectory.json --strict
```

## 评估

探索时不要为了分数优化路径，只在结束后评估。建议观察信息环境跨度、路径可解释性、语义位移、新问题生成、解释修正、人机联合增益、来源完整度和跨轮重复。详见 [`benchmark/README.zh-CN.md`](benchmark/README.zh-CN.md)。

## 重要边界

CoExplore 是发现协议，不是真相机器。保留来源，区分观察与推断，重要结论在发布或行动前另行验证。不要把私人浏览记录、账号凭证和敏感个人信息提交到公开仓库。
